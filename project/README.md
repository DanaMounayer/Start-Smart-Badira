# BADIRA — StartSmart Record

The working record of **BADIRA | بادرة** in the **StartSmart Universities Challenge**: what was done
in each stage of the competition, and what each stage produced.

The prototype's own documentation lives at the repository root ([`README.md`](../README.md),
[`docs/`](../docs)). This folder holds the competition work behind it.

**Dana Al Mounayer & Jwdee Alimam** · Effat University

> tracked in its own repository. This one is StartSmart.

## How this folder is organised

```
project/
├── stage-1-startsmart-workshops/        # round 1
│   ├── pitch-deck/
│   ├── business-model-canvas/
│   └── prototype-v1/                    # v1 = the prototype at the repository root
└── stage-2-startsmart-final/            # now
    ├── task-1-clinical-understanding/
    ├── task-2-finding-the-data/
    ├── task-3-judge-channel/
    └── Week-Plan (20-26 September)/     # one folder per week
```

**The prototype's code is not copied into Stage 1.** It lives at the repository root, where it
builds and deploys from. `stage-1/prototype-v1/` records that it is v1 and holds the screenshots.

Every document is committed as both `.docx` (editable) and `.pdf` (readable in the browser without
downloading). Click any `.pdf` to read it here on GitHub.

---

## What is deliberately not here

No patient data, no clinical records, and no signed data use agreements. This repository is public.
Data obtained under a DUA stays out of version control entirely — only the analysis and the
documentation live here.
