# BADIRA — Project Record

The working record of **BADIRA | بادرة**, a self-adaptive framework for predicting the risk of
pregnancy complications, built as **Senior Project I** at Effat University and entered in the
**StartSmart Universities Challenge**.

The prototype's own documentation lives at the repository root ([`README.md`](../README.md),
[`docs/`](../docs)). This folder holds the project behind it: what was done, in what order, and
what each stage produced.

## What is deliberately not here

No patient data, no clinical records, and no signed data use agreements. This repository is
public. Data obtained under a DUA stays out of version control entirely — only the analysis
and the documentation live here.
