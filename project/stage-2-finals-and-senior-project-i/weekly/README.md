## How to add a week

1. Create a folder named `week-NN_<month-range>` — e.g. `week-02_sep-27-oct-03`.
2. Drop the week's plan in it.
3. Copy [`_TEMPLATE.md`](_TEMPLATE.md) in as `README.md` and fill it in.
4. Add a row to the table above.

Three lines per week is enough. The point is the trail, not the prose.
