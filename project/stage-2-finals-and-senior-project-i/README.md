## What this stage is proving

> There are two ways to find a woman at risk before she is sick, and one way to confirm she is sick.
> Each needs different things to be available.

Task 1 establishes that picture from the clinical guidelines. Task 2 asks which data could support a
model inside it. The proposal sets out the framework that would use it.

---

## The framework, as currently defined

BADIRA is a **self-adaptive framework for predicting the risk of pregnancy complications**. It builds
a standardised profile of each woman, measures the quality of the available data, and selects the
model and prediction settings that the data can actually support — so the framework adapts to the
population it is given rather than assuming one.

It is tested first on **preeclampsia**, then extended to **preterm birth** and **gestational diabetes**.
