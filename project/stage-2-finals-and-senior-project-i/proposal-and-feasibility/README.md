## The feasibility verdict

Feasible as scoped. No dimension returns a blocking result. The one real risk is **schedule**, and
only through **data access** — the single step whose timing is not under the team's control, which is
why three applications run in parallel and the Data Profiler is developed on public data meanwhile.

No external funding is required: the datasets are free for academic research, the software stack is
open source, and the compute runs on student machines.
